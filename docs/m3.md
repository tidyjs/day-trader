# Milestone 3: catalyst classifier

SPEC 6, with `claude-haiku-5-5`. The model's output is one input to the deterministic rules. It never picks names, sets levels or sizes positions.

## Pipeline (`src/catalyst.py`)

1. **News:** Alpaca news for the 48 h up to the **scan time** (news isn't delayed like SIP; anything created after the scan time is dropped). Recent filings (5 days) come from the EDGAR inputs.
2. **Roundups dropped:** items tagged with more than 3 symbols are removed before the model sees them.
3. **No items and no filings:** status `no_news` and catalyst `none`, with **no model call**.
4. **One call per company:** the prompt gives the company name, ticker, items and filing titles, and says other companies' news doesn't count. Structured JSON output (section 6 schema), at effort `low`.
5. **Validated in code:** exact keys, enum type, integer quality 0-5, booleans. Retried once. Two failures, an API error, a refusal or a truncated answer all mean `unavailable`, which is a warning and the rule becomes `unknown`.
6. **Name check:** if no remaining item mentions the company (name with suffixes stripped, accents folded, a distinctive first word for long names) or ticker, the output is forced to `none` with quality 0. The model's own answer is kept as `model_output` for the audit trail.

Each classification and its news are saved in the scan's inputs, so `--replay` reproduces them without calling the model.

## Rule: `dq_promo_or_no_catalyst` (SPEC 4.2)

- **fail** if the promo/pump flag is set or the type is `promo`.
- **fail** if the type is `none` **and** there was no prior-day volume surge: prior-day volume under 3x its 20-session average, the same thresholds as continuation.
- **unknown** if the classifier is unavailable, or there's no catalyst and the surge can't be computed (short history).
- **Warning** (4.3): dilution language in the news with no offering filing found.

New `candidates.csv` columns: `catalyst_status`, `catalyst_type`, `catalyst_quality`, `catalyst_summary`, `catalyst_forced_none`, `news_used`, `news_dropped_roundup`, `prior_day_volume_multiple`. `catalyst_quality` is the score input for M4.

## Tests

- **Unit tests with a fake client** (`tests/test_catalyst.py`):
  - name parsing and mention matching, including short tickers and accents
  - roundup dropping and the no-news path (no call)
  - validation, retry once, two failures, API error, refusal
  - every wrong-company case is forced to `none` even when the fake model is "fooled"
  - row-level rule outcomes (`tests/test_scan.py`)
- **Fixed test set** `tests/data/catalyst_cases.json` (14 cases):
  - 8 right-company cases: earnings, patent, compliance notice, debt-to-equity conversion, registered direct, promo, FDA
  - **5 wrong-company cases:** other companies' merger, earnings and FDA news tagged with the gapper's ticker, including one where the gapper's ticker appears in the other company's story, so the name check can't help and only the model can get it right
  - 1 mixed case (own minor news plus another company's merger)

### Live eval, `python -m src.catalyst --eval` (2026-11-15)
