# Milestone 2: filters and flags

SPEC 4.1-4.3 on top of the M1 scanner, with a pass/fail column per rule in `data/candidates.csv`.

## Rule order (cheapest first)

| Step | Rules | Source | Who gets it |
|---|---|---|---|
| 1 | price, gap, T212, premarket $ volume >= $100k, premarket trades >= 50 | bars already fetched in M1 | every name |
| 2 | continuation, prior close in top 25% of range | Alpaca daily bars, 1 batched call | every candidate |
| 3 | offering and reverse-split disqualifiers; deficiency, stale-shares and possible-offering warnings | EDGAR (official, 10 req/s; spaced to about 6/s) | every candidate |
| 4 | spread warning | SIP quotes, last 2 min before the cutoff | only names passing every rule above |
| 5 | float < 50M; Yahoo vs EDGAR shares warning | Yahoo, one call per 1.5 s | only names passing every rule above |

Because steps 4-5 are gated, `rule_float` is blank ("not checked") for names that already failed. All other rules are filled in for every candidate, so the log can later show which rules remove losers and which only remove names.

## candidates.csv columns

- **Status columns** (`pass` / `fail` / `unknown` / blank = not checked):
  - Must-pass rules: `rule_price`, `rule_gap`, `rule_t212`, `rule_pm_dollar_volume`, `rule_pm_trades`, `rule_continuation`, `rule_prior_range`, `rule_float`.
  - Disqualifiers: `dq_offering`, `dq_reverse_split`, and `dq_promo_or_no_catalyst` (blank until the M3 classifier).
- **What each rule tested:** `continuation_detail`, `prior_range_pos_pct`, `float_shares`, `float_source`, `edgar_shares_out`, `edgar_shares_asof`, `yahoo_shares_out`, `spread_pct`, `dq_reasons`.
- **`eligible`:** every must-pass rule passes (float may be `unknown`, which is a warning per 4.3) and nothing disqualifies.

## Decisions encoded (all from SPEC or M0/M2 findings)

- **Unknown rules.**
  - Unknown continuation (short history) means **not eligible**, because it is a must-pass rule.
  - Unknown float or unknown EDGAR (no CIK) stays eligible with a warning, per 4.3.
- **Offering.**
  - Disqualify on 8-K item 3.02.
  - Disqualify on an offering form (424B\*/S-1/S-3/F-1/F-3) with equity wording on its cover.
  - Disqualify on an 8-K or **6-K** with offering *and* equity wording in the same passage. 6-K covers foreign filers, which are many of these names.
  - Anything weaker becomes a "possible offering" warning. An offering form that couldn't be read is also a warning, never a silent pass.
- **Reverse split, judged per sentence.**
  - Approve / authorize / ratio / consolidated shares / a future effective date: disqualify.
  - Completed before the scan day: warning.
  - Warrant-adjustment boilerplate and "may need to" risk factors: ignored.
  - Any other mention: "possible reverse split" warning.
- **No look-ahead.**
  - EDGAR filings count if accepted at or before the scan time. EDGAR isn't delayed like SIP, and its `acceptanceDateTime` was checked to be true UTC.
  - EDGAR shares outstanding count only if filed before the scan day.
  - Daily history stops at the prior session.

## Data facts checked while building

- Alpaca daily **high/low are regular-session only**, so prior range is a proper 09:30-16:00 range. Daily **volume includes extended hours**, so the continuation volume multiple compares like with like.
- Renamed tickers keep their Alpaca history under the new symbol (CRMN, formerly KAZR).
- SIP historical quotes work on free keys.

## Bugs found while building

- **Float rounding:** 1.20 / 1.00 − 1 = 19.999…%, so an exact +20% close failed continuation. Comparisons are now rounded.
- **Nanosecond timestamps:** Alpaca quote timestamps have nanoseconds, which Python 3.9 can't parse. They're now cut to microseconds.
- **Reverse-split false positives:** the first version disqualified on any mention, and 4 of the 8 matches were wrong (a completed split, two warrant clauses, a risk factor). The real excerpts are now test cases.

### MRLN (11-13), disqualified by `dq_offering`: report only, rule unchanged
- Matched sentence: "Our shares of Common Stock are listed on the Nasdaq Stock Market LLC under the symbol 'MRLN'." This is boilerplate on almost every prospectus cover.
- The filing (424B3, accepted 09:00 and 09:02 ET) is **Prospectus Supplement No. 4**. It only attaches the 10-Q filed 11-12 to an existing registration. It is not a new offering.
- The underlying registration (S-1 333-295578, effective 2026-05-13) is a **resale by a selling stockholder**: "up to 13,336,000 shares … We will not receive any proceeds". It is **not a primary raise**.
- So this is a false positive for a "new offering" rule. Any company with an active resale shelf files these supplements after each 10-Q or 8-K. The cover-equity test for `424B*` therefore needs refining. Options for your decision, not implemented:
  - ignore prospectus supplements that only incorporate a periodic report
  - treat resale (selling-stockholder) registrations as a warning instead of a disqualifier
  - require a share count or price on the cover
